# CRJ Descent

Idle-descent planner for the CRJ900. This repository is the public GitHub Pages site for the app.

**Live app:** https://benirvine18.github.io/crj-descent/

Add that link to your Home Screen, then delete the old Netlify icon. The previous Netlify address is left alone and is no longer updated.

The service worker is network-first: after a new publish, close the Home Screen app fully and reopen it while online to pick up the update.
